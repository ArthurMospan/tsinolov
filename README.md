# 🛒 Цінолов (Smart Watchlist Bot) 

**Цінолов** — це розумний автономний помічник для гостей «Сільпо» та Loko, створений в рамках хакатону **Сільпо AI Factory**. Він дозволяє клієнтам зручно керувати своїми улюбленими товарами та отримувати персоналізовані push-сповіщення в Telegram при зміні цін або наявності.

---

## 🎯 Проблема, яку ми вирішуємо
Часто гості додають товари в "Обране", щоб дочекатися знижки, але забувають перевіряти їх. **Цінолов** працює як пасивний радар: клієнт встановлює свою "Стелю ціни" (Target Price), і як тільки ціна товару падає нижче цього рівня або з'являється крута акція (Smart Buy) — система автоматично надсилає сповіщення.

## 🛠 Архітектура та Технології
Проєкт розділено на дві частини для забезпечення найкращого UX (User Experience):

1. **Frontend (Telegram Mini App)**
   - **Стек:** React, Vite, CSS (Glassmorphism, фірмовий стиль Сільпо).
   - **Роль:** Графічний інтерфейс для налаштування сповіщень та керування "Обраним". Користувач не має спілкуватися з ботом текстом — все відбувається у зручному візуальному застосунку.

2. **Backend (Node.js + MCP Client)**
   - **Стек:** Node.js, Express.js, Telegraf, SQLite, node-cron.
   - **Роль:** API-сервер для Web App, фоновий сканер (`scanner.ts`) для моніторингу цін, та інтеграція з офіційним сервером **Сільпо MCP** (Model Context Protocol).

---

## 🔌 Інтеграція з Сільпо MCP
Ми використовуємо `@modelcontextprotocol/sdk` (Streamable HTTP) для прямого зв'язку з `https://mcp.silpo.ua/mcp`. 
Наш бекенд періодично опитує MCP-сервер через доступні tools (наприклад, `silpo_get_my_favorites`, `silpo_get_promotions`, `silpo_find_products_batch`), аналізує отримані дані локально і приймає рішення про відправку повідомлення гостю.

## 🚀 Як запустити локально

### 1. Клонування репозиторію
```bash
git clone <URL_твого_репозиторію>
cd silpo-ai-factory
```

### 2. Запуск Backend (Бот + API)
```bash
cd bot
npm install
```
Створіть файл `.env` у папці `bot`:
```env
BOT_TOKEN=ваш_telegram_bot_token
WEBAPP_URL=посилання_на_ваш_фронтенд (напр. Vercel або ngrok)
SILPO_MCP_TOKEN=токен_авторизації_з_хакатону
```
```bash
npm run dev
```

### 3. Запуск Frontend (Web App)
```bash
cd ../webapp
npm install
npm run dev
```

## 📱 Демонстрація функціоналу
- **Зниження ціни (Price Drop):** Сповіщає, якщо поточна ціна стала меншою за ту, при якій товар додали в обране.
- **Цільова ціна (Target Price):** Можливість вказати точну суму (напр. "Хочу купити, коли буде дешевше 50 грн").
- **Smart Buy:** Аналітика історичного мінімуму та крутих акцій.
