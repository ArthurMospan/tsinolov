# 🛒 Smart Watchlist Bot (Сільпо/Loko) - MVP

Telegram-бот для автоматичного моніторингу списку обраних товарів клієнта у "Сільпо" або "Loko".

## 🌟 Основний функціонал
Бот періодично підключається до профілю користувача через Сільпо MCP та перевіряє стан його "Обраного" (або кастомних списків). На основі гнучких налаштувань користувача бот відправляє сповіщення про:
- 📉 Зниження цін (або досягнення бажаної ціни).
- 🔥 Нові акції та персональні пропозиції.
- 📦 Появу товару в наявності чи можливість доставки.
- 🔄 Вигідні альтернативи (дешевший аналог або краща ціна за 1 кг/л).
- 🧠 Smart Buy (вигідна комбінація або історичний мінімум ціни).

## 🛠 Технологічний стек
- **Backend**: Node.js, TypeScript
- **Telegram API**: `telegraf`
- **Database**: SQLite (`better-sqlite3`)
- **Background Jobs**: `node-cron`
- **Silpo API**: Integration via MCP endpoints (`silpo_get_my_favorites` тощо).

## 🚀 Встановлення та запуск

1. Клонуйте репозиторій або перейдіть до директорії `bot`.
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Створіть файл `.env` на основі `.env.example` та додайте ваш `BOT_TOKEN` від [BotFather](https://t.me/BotFather).
4. Запустіть базу даних (автоматична ініціалізація):
   ```bash
   npm run db:init
   ```
5. Запустіть бота:
   ```bash
   npm run dev
   ```

## ⚙️ Структура проєкту
- `src/bot/` — логіка Telegram-бота, меню налаштувань.
- `src/db/` — ініціалізація SQLite та запити.
- `src/api/` — клієнт для Сільпо API та OAuth.
- `src/worker/` — фонові процеси (cron) для сканування змін.
- `src/notifier/` — логіка формування та відправки сповіщень.

## 🍊 Дизайн
Всі повідомлення бота витримані в преміальному стилі, який імітує візуальну мову Сільпо за допомогою структурованого тексту та тематичних емодзі (🛒, 🧡, 🥖, 🍊).
