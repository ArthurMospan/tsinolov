## 🎯 Топ-4 Концепції Проєктів для Хакатону

### 1. 🥑 «Сільпо Gourmet Master» — Інтелектуальний AI-Шеф & Закупник
**Концепція:** Персональний AI-кулінарний асистент, який складає раціон/меню під індивідуальні дієтичні обмеження та сімейний профіль, після чого автоматично збирає оптимальний кошик і оформлює доставку в «Сільпо».

* **Ключові MCP Tools:**
  * `silpo_get_my_food_restrictions` — зчитування дієт (gluten-free, lactose-free, vegan тощо).
  * `silpo_get_my_family` — врахування профілів дітей та тварин.
  * `silpo_find_products_batch` — пакетний пошук усіх інгредієнтів рецептів.
  * `silpo_get_replacements` — автозаміна відсутніх інгредієнтів.
  * `silpo_get_loyalty_info` & `silpo_update_shopping_cart` — автосписання балабонусів.
  * `silpo_get_time_slots` — вибір зручного вікна доставки.

---

### 2. 💰 «Сільпо Budget Guardian» — AI-Оптимізатор Бюджету та Акцій
**Концепція:** Розумний помічник для економного та раціонального шопінгу. Гість задає тижневий бюджет, а агент самостійно підбирає найвигідніший набір покупок на основі персональних знижок та акцій магазину.

* **Ключові MCP Tools:**
  * `silpo_get_promotions` & `silpo_get_my_promos` — аналіз активних знижок.
  * `silpo_get_my_coupons` & `silpo_get_promo_codes` — застосування персональних купонів.
  * `silpo_get_my_favorites` — збереження вподобань гостя.
  * `silpo_add_or_update_cart_products` — наповнення кошика в межах заданого ліміту ₴.

---

### 3. 🔄 «Сільпо Smart Restock» — Автономний AI-Асистент Запасу Дому
**Концепція:** AI-сервіс регулярного поповнення запасів. Аналізує історію покупок (онлайн та чеки з фізичних супермаркетів) і завчасно нагадує про товари, які скоро закінчуються.

* **Ключові MCP Tools:**
  * `silpo_get_my_offline_orders` — аналіз звичок покупок в супермаркеті.
  * `silpo_get_my_online_orders` — історія онлайн-замовлень.
  * `silpo_get_my_shopping_cart` & `silpo_update_shopping_cart` — створення чернетки замовлення в 1 клік.

---

### 4. 🎉 «Сільпо Party Planner» — AI-Організатор Заходів
**Концепція:** Агент для розрахунку та збірки продуктів під вечірки, пікніки, дні народження або корпоративи з розрахунком кількості людей, дієт та загального кошторису.

* **Ключові MCP Tools:**
  * `silpo_get_product_sets` — кураторські добірки товарів.
  * `silpo_find_products_batch` — пошук потрібної кількості напоїв та їжі.
  * `silpo_find_address` & `silpo_get_available_delivery_types` — доставка на локацію проведення події.

---

## 🛠 Технічний стек проєкту

* **Backend / Agent Core:** Node.js / TypeScript з `@modelcontextprotocol/sdk` або Python з `mcp`.
* **Frontend / Interface:** React (Vite) + TailwindCSS + Framer Motion (сучасний інтерактивний інтерфейс).
* **AI Engine:** Anthropic Claude / OpenAI GPT-4o / Gemini з інтеграцією через MCP client.
